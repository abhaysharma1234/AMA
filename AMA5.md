## What is O in SOLID Principles?
O stands for **Open/Closed Principle** — software entities should be open for extension but closed for modification.

## What is a superuser?
A superuser is an admin account with full permissions to manage the entire system without restrictions.

## Difference between Grid and Flexbox?
Grid is a **2-dimensional layout system** (rows and columns), while Flexbox is **1-dimensional** (row or column).

## What is a checkpoint?
A checkpoint is a saved state of a system or database that allows recovery to a consistent point in case of failure.

## What is the use of secret key?
A secret key is used for **security purposes** like hashing, signing sessions, and protecting data from tampering.

## What is SQL Injection attack?
SQL Injection is a vulnerability where attackers inject malicious SQL queries to manipulate or access the database.

## What is a query parameter?
A query parameter is a key-value pair in a URL used to pass data to the server (e.g., `?id=10`).

## What is A in ACID?
A stands for **Atomicity** — a transaction is either fully completed or not executed at all.

## How to run Django server on a specific IP address?
Use the command:  
`python manage.py runserver <IP>:<PORT>`  
Example: `python manage.py runserver 192.168.1.10:8000`

## What is Django Forms?
Django Forms are tools to handle **form creation, validation, and processing** in a structured way.

## How to create a new app in Django?
Use the command:  
`python manage.py startapp app_name`

## Why use DEBUG = False in production?
It disables detailed error messages to prevent exposing sensitive information and improves security.

## What is Normalization?
Normalization is the process of organizing database tables to **reduce redundancy and improve data integrity**.

## What is S in SOLID?
S stands for **Single Responsibility Principle** — a class should have only one reason to change.
