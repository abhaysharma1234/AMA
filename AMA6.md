

### 1. What is `ALLOWED_HOSTS` in Django?

`ALLOWED_HOSTS` is a security setting in Django that defines a list of domain names or IP addresses that your application can serve. It helps prevent HTTP Host header attacks by allowing only trusted hosts.

---

### 2. What is the use of `urls.py` in Django?

`urls.py` is used to map URLs (web addresses) to views (functions or classes). It acts as a routing system that decides which code should handle a particular request.

---

### 3. What is authentication?

Authentication is the process of verifying the identity of a user, typically using credentials like username and password, to ensure they are who they claim to be.

---

### 4. What is the media folder in Django?

The media folder is used to store user-uploaded files such as images, videos, and documents. It is different from static files and is usually configured using `MEDIA_ROOT` and `MEDIA_URL`.

---

### 5. What is a widget in Django?

A widget in Django defines how a form field is rendered in HTML. For example, a `TextInput`, `Checkbox`, or `Select` widget controls the appearance of the input field.

---

### 6. What does an async function return?

An async function returns a coroutine object. It does not execute immediately and must be awaited using `await` to get the actual result.

---

### 7. How does CLI help us?

The Command Line Interface (CLI) allows developers to interact with the system using commands. It helps in running scripts, managing projects, automating tasks, and executing Django commands like `runserver` and `migrate`.

---

### 8. Why do we use the Meta class in Django?

The Meta class in Django is used to define metadata for models, such as ordering, table name, verbose names, and constraints. It customizes the behavior of the model without affecting its fields.

---

### 9. What is method overriding in Python?

Method overriding occurs when a child class provides a specific implementation of a method that is already defined in its parent class. It is used to change or extend the behavior of inherited methods.

---

### 10. What are decorators in Python?

Decorators are functions that modify the behavior of another function without changing its code. They are commonly used for logging, authentication, permissions, and caching.
